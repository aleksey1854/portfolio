Video Compressor

Сжатие видео через FFmpeg. Три пресета качества плюс конвертация форматов. Форма ниже собрана автоматически — из manifest.json модуля, без единой строки интерфейсного кода.

"ui": "auto" type: python category: Media entrypoint: main.py
Параметры запуска 3 поля из manifest.json
Видео-файл *
D:\Media\raw\interview-2026-09.mov 1,4 ГБ
Качество *
medium (баланс)
Формат вывода *
mp4 webm mov

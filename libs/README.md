# Библиотеки

Все лежат локально, сайт не ходит за ними в интернет.

| файл | библиотека | версия | лицензия | откуда |
|---|---|---|---|---|
| `gsap.min.js`, `ScrollTrigger.min.js` | GSAP | 3.15.0 | GSAP Standard License (бесплатно) | gsap.com |
| `lenis.min.js` | Lenis | 1.3.26 | MIT | github.com/darkroomengineering/lenis |
| `vanilla-tilt.min.js` | vanilla-tilt | 1.8.1 | MIT, © 2017 Șandor Sergiu (micku7zu), текст лицензии в `LICENSE-vanilla-tilt.txt` | github.com/micku7zu/vanilla-tilt.js |
| `img-comparison-slider.js` | img-comparison-slider | 8.0.7 | MIT (по package.json), автор sneas | github.com/sneas/img-comparison-slider |

GSAP и ScrollTrigger грузятся только на экранах от 1024×680 (стопка карточек),
Lenis — только при мыши. vanilla-tilt и img-comparison-slider — только на ПК
с мышью и без «уменьшать движение».
